# Duoodo

Little doodles for your favourite person. Draw or write something, and it appears on your partner's phone and home-screen widget.

- **Private by design:** end-to-end encrypted. Doodles travel over public Nostr relays as unreadable data, and there are no accounts and no server of our own.
- **Two people, paired once:** pair with a QR code or a one-time code, and stay paired until one of you unpairs.
- **Minimal permissions:** internet and notifications only. No storage, contacts, location, camera or microphone access.

## Download

Get the latest APK from **[Releases](../../releases/latest)** and install the same version on both phones. Android 8.0 or later is required.

Each release lists the APK's SHA-256 checksum and the signing certificate fingerprint, so you can confirm the file is genuine:

```
sha256sum -c Duoodo-vX.Y.Z.apk.sha256
apksigner verify --print-certs Duoodo-vX.Y.Z.apk
```
